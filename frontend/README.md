# Frontend

The React and TypeScript interface for Support Case Classifier.

Run commands from this directory:

```powershell
npm.cmd install
npm.cmd run dev
```

Quality checks:

```powershell
npm.cmd run lint
npm.cmd test
npm.cmd run build
```

The frontend expects the API at `http://127.0.0.1:8000/api`. Override it with
`VITE_API_BASE_URL` when needed. See the repository root README for complete
backend setup, privacy notes, and VS Code instructions.
